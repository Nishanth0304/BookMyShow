# BookMyShow Clone

A fully responsive **BookMyShow Clone Website** built using **HTML5 and CSS3**.  
This project replicates the core UI of BookMyShow with multiple pages like Movies, Events, Sports, Offers, Sign In, Create Account, Contact, Help Center, Privacy Policy, and Terms & Conditions.

The project is fully responsive and works on **mobile, tablet, laptop, and desktop screens**.

---

# Features

✅ Fully Responsive Design  
✅ Responsive Navigation Bar
